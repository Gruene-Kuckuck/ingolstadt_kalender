# Sitzungstermine Ingolstadt als Kalender abonnieren

Die Termine von Stadtrat, Ausschüssen und Bezirksausschüssen – automatisch aktualisiert.

## So abonniert ihr einen Kalender

**iPhone:** Einstellungen → Kalender → Accounts → Account hinzufügen → Abonnierten Kalender hinzufügen → Link einfügen

**Google Kalender:** calendar.google.com → links **+** → per Link abonnieren → Link einfügen

**Thunderbird/Outlook:** Neuer Kalender → Im Netzwerk → Link einfügen

## Hinweise

- Aktualisierung täglich um ca. 5 Uhr; der Zeitraum umfasst die im [Ratsinfoportal](https://www.ingolstadt.de/sessionnet/info.php) angezeigten Termine
- Termine ohne Uhrzeit sind geplante Sitzungstermine (Ganztages-Eintrag)
- Angaben ohne Gewähr – verbindlich ist das offizielle Ratsinfoportal
